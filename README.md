# 个人网站

这是一个可直接修改、预览、上线的高级程序员风格个人网站。当前版本是纯静态项目，不依赖复杂构建工具，适合继续扩展成博客、作品集或在线简历。

## 本地运行

```bash
npm run dev
```

然后打开：

```text
http://localhost:4173
```

## 常用修改位置

- `index.html`：页面结构、标题、邮箱、导航和主文案。
- `script.js`：核心能力、代表项目、技术栈、职业经历等可配置内容。
- `styles.css`：视觉风格、布局、响应式样式。
- `assets/hero-workspace.png`：首页首屏图片，可替换成你的头像、工作照或项目截图。
- `.openai/hosting.json`：Sites 发布配置，已绑定当前站点项目 ID。

## 发布说明

这个仓库已经包含发布所需的 Sites 项目配置。后续修改后，提交代码、保存新版本并部署即可发布到生产地址。
