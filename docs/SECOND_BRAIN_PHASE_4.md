# 第二大脑第四轮：检索与回顾

## 本轮目标

让已经沉淀的内容能够被快速找回，并通过可持续的回顾计划重新进入日常工作，而不是只停留在数据库中。

## 已完成

### 1. 后台统一搜索

- 新增 `GET /admin/workspace/search`。
- 统一检索文章、知识节点、知识专栏、文档和项目。
- 后台搜索包含私有内容、草稿与未发布内容，不受公开站点可见性规则限制。
- 搜索结果提供内容类型、状态、可见性、摘要和对应编辑器入口。
- 顶部 `Command + K` 搜索框按回车后进入统一检索页面。

### 2. 持久化回顾计划

- 新增 `review_states` 数据表和 Alembic 迁移 `20260718_0010`。
- 每条内容可记录回顾状态、间隔天数、累计次数、上次回顾和下次回顾时间。
- 支持加入今日队列、完成回顾、延期到明天等动作。
- 完成回顾后自动计算下一次回顾日期。
- 回顾操作写入统一活动日志。

### 3. 检索与回顾工作区

- 后台增加独立的“检索与回顾”导航和页面。
- 页面由统一搜索、今日回顾、最近修改、关联推荐四部分组成。
- 最近修改帮助继续尚未完成的工作。
- 关联推荐优先使用专栏、文章、节点和文档之间的真实关系；关系不足时按连接度补充。
- 所有结果都能直接跳转到对应编辑器。

### 4. 自适应与可靠性

- 桌面端采用主队列与辅助信息双栏布局。
- 900px 以下自动切换为单栏。
- 560px 以下搜索控件和回顾操作自动换行。
- 390px 视口检查无横向溢出，页面控制台无错误。

第五轮应把“回顾”进一步变成可执行的日常流程：增加自定义回顾间隔、批量安排、回顾备注编辑、每日工作台摘要，以及基于语义检索和知识关系的更精准推荐。
