# 第二大脑第九轮：AI 评测与反馈闭环

## 本轮目标

把已有的一次性 RAG 和 Agent 评测升级为可维护固定样本、可保存运行历史、可追踪版本并能自动发现回退的质量系统。

## 已完成

### 1. 固定评测集

- 新增独立的 AI 评测集模型。
- 支持 RAG 与 Agent 两类评测集。
- 样本使用结构化 JSON，可在后台维护。
- 单个评测集最多保存 50 条固定样本。
- 首次使用自动创建 RAG 核心检索和 Agent 工具路径两个默认评测集。
- 默认数据只创建一次，不会重复插入。

### 2. 评测集版本

- 每次修改名称、说明、类型或样本都会递增版本。
- 历史运行保存当时的评测集版本。
- 后续编辑不会改变旧运行的样本和结果解释。

### 3. 运行历史

- RAG 评测保存召回率、期望命中率、Top1、MRR、平均分数和逐样本来源。
- RAG 每次自动比较 balanced、semantic 和 keyword 三种检索配置。
- Agent 评测保存成功率、工具路径、来源命中、质量、延迟与成本。
- Agent 支持本地规划和真实模型规划两种明确运行方式。
- 运行结果、耗时和完整 case 详情持久化保存。

### 4. 自动回归判断

- 相同评测集和相同模式自动与上一次成功运行比较。
- 首次运行标记为 `baseline`。
- 差异在容差内标记为 `stable`。
- 主要指标提升标记为 `improved`。
- 主要指标下降超过阈值标记为 `regressed`。
- RAG 主要指标使用 MRR，Agent 主要指标使用成功率。

### 5. 失败审计

- 评测开始时先创建 `running` 记录。
- 执行异常时记录转为 `failed`。
- 错误摘要、运行 ID 和活动日志均被保留。
- 失败不会伪装成零分成功运行，也不会静默消失。

### 6. 后台评测工作台

- 新增独立评测集列表和编辑器。
- 支持创建、编辑、启停和版本显示。
- 支持直接编辑固定样本 JSON。
- 支持本地运行和 Agent 模型运行。
- 历史列表显示基线、稳定、提升与回退。
- 运行详情显示逐样本结果和 RAG 配置对比。
- 移动端自动改为单列，不产生横向溢出。

## 数据模型

- `ai_eval_suites`：评测集、固定样本、类型和版本。
- `ai_eval_runs`：运行结果、指标、回归结论、耗时和执行状态。
