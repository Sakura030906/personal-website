# 第二大脑第二轮交付说明

完成日期：2026-07-18

## 本轮目标

统一文章、知识节点和文档的编辑体验，让长期维护内容时可以明确知道当前编辑对象、保存状态、发布准备度和历史变化，并更容易建立跨内容关联。

## 已完成

### 1. 统一编辑器状态栏

- 文章、知识节点和文档使用一致的编辑器顶部状态区。
- 状态区显示内容类型、标题、可见性和保存状态。
- 保存状态区分未保存、正在保存、已保存和保存失败。
- `Command/Ctrl + S` 会根据当前后台页面保存对应内容。

### 2. 自动保存

- 文章继续使用草稿自动保存机制。
- 已创建的知识节点在停止输入约 2.4 秒后自动保存。
- 文档元数据在停止输入约 2.8 秒后自动保存。
- 离开知识节点或文档页面前会尝试提交尚未保存的修改。
- 页面关闭前若仍有未保存或正在保存的内容，浏览器会给出提示。

### 3. 发布与内容就绪检查

- 文章检查标题、URL、摘要、正文、标签、封面、SEO 和所属专栏。
- 知识节点检查标题、摘要、正文、专栏、标签或文章关联以及 AI 检索权限。
- 文档检查解析状态、有效切片、摘要、专栏和知识节点关联。
- 发布文章时若仍有缺失项，会展示缺失清单并要求确认，不会静默发布不完整内容。

### 4. 版本历史与差异

- 文章、知识节点和文档都可以查看历史版本。
- 知识节点新增字段变化和 Markdown 正文差异接口。
- 文档新增元数据、关联和切片正文差异接口。
- 后台版本列表支持“查看差异”和“恢复”。
- 恢复前会保留当前状态，避免版本恢复覆盖后无法找回。

### 5. 跨内容关联选择

- 知识节点编辑器可搜索并筛选所属专栏和关联文章。
- 文档编辑器可搜索并筛选关联知识节点。
- 文章继续使用专栏选择和自动关联建议，形成文章、专栏、节点和文档之间的关联入口。
- 大量关联项不会再要求逐项滚动查找。

### 6. 安全删除文案

- 知识节点和文档删除操作统一表述为“移至回收站”。
- 明确提示内容、关系、切片和版本会被保留。

## 验证结果

- 后端自动化测试：43 项全部通过。
- 新增知识节点版本差异测试。
- 新增文档切片版本差异测试。
- Python 编译检查通过。
- 管理后台 JavaScript 语法检查通过。
- Git 差异格式检查通过。
- 前端生产构建通过。
- 桌面端与 390px 手机宽度视觉检查通过，无横向溢出。

## 当前边界

- 新知识节点需要第一次手动保存，创建成功后才进入自动保存流程。
- 文档切片仍按单个切片手动保存，避免编辑父级元数据时意外覆盖切片内容。
- 发布准备度是质量提示，不是强制门禁；确认后仍可发布特殊或短内容。

## 第三轮建议

下一轮重点应从“可靠编辑”转向“知识组织”：统一关联管理页面，增加反向链接与孤立内容检查，并让收件箱内容可以通过一个整理流程同时选择专栏、节点、标签和目标内容类型。
