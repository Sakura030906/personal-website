# 第二大脑第五轮：日常回顾工作流

## 本轮目标

把第四轮的“回顾列表”升级为可以每天实际使用的工作流，让检索、安排、复习、记录和再次提醒形成闭环。

## 已完成

### 1. 每日摘要

- 显示当天记录数量、内容修改数量和已回顾数量。
- 计算连续回顾天数。
- 显示下一条计划回顾时间。
- 未登录或数据未加载时自动隐藏空摘要，不留下无意义占位。

### 2. 自定义回顾

- 单条内容支持 1–365 天的自定义回顾间隔。
- 支持填写回顾备注，记录当前理解、疑问和下次关注点。
- 支持“保存并完成”和“仅安排时间”两种操作。
- 已有备注在普通延期时不会被空内容覆盖。

### 3. 批量工作流

- 今日队列支持单选、全选和半选状态。
- 支持批量加入今日回顾。
- 支持按统一间隔批量完成回顾。
- 后端单次最多处理 100 条，并验证每个目标真实存在。
- 项目也已纳入统一回顾实体范围。

### 4. 搜索到回顾

- 后台搜索结果可以直接加入今日回顾。
- 仍可从搜索结果直接打开对应编辑器。
- 搜索、编辑和回顾不再是彼此分离的流程。

### 5. 推荐质量

- 优先使用真实知识关系生成推荐。
- 关系不足时结合标题、摘要的中英文内容相似度。
- 同时参考实体连接度，避免推荐结果完全随机。
- 推荐原因以“同一专栏、引用关系、内容相似、知识枢纽”等可读文案展示。

### 6. 未来计划

- 新增“接下来”区域，展示已经安排的未来回顾。
- 到期内容、尚未回顾内容和未来计划现在有明确区分。

## API

- `GET /admin/workspace/review`：回顾统计、每日摘要、今日队列、未来计划、最近修改与推荐。
- `POST /admin/workspace/review/{entity_type}/{entity_id}`：单条安排、完成或延期。
- `POST /admin/workspace/review/batch`：批量安排或完成。
