# 第二大脑第三轮交付说明

完成日期：2026-07-18

## 本轮目标

把分散在文章、知识节点、专栏和文档中的关系整合为可查看、可追踪的知识组织系统，并让收件箱内容可以一次完成分类和关联后进入正式编辑流程。

## 已完成

### 1. 统一关系工作台

- 后台“知识关系”页面新增独立的关系工作台。
- 同时统计知识专栏、文章、知识节点和文档。
- 统一展示专栏包含、文章引用、文档引用和节点语义关系。
- 支持按标题或 URL 标识搜索。
- 支持按内容类型筛选。
- 支持只查看孤立内容。
- 选择内容后显示正向关系和反向链接。
- 可以从关系详情直接进入对应文章、节点、文档或专栏编辑器。

### 2. 反向链接接口

- 新增统一组织数据接口：`GET /admin/workspace/organization`。
- 新增反向链接接口：`GET /admin/workspace/backlinks/{entity_type}/{entity_id}`。
- 接口不依赖旧 JSON 关系字段，直接读取标准化数据库关系。
- 同一套接口可以继续供未来知识图谱、AI Lab 和内容健康检查使用。

### 3. 孤立内容检查

- 自动识别没有任何专栏、节点、文章或文档关系的内容。
- 工作台统计孤立数量，并提供专门筛选开关。
- 孤立项使用独立状态文案，不与普通内容混在一起。
- 不自动猜测或创建关系，避免错误连接污染知识网络。

### 4. 收件箱一站式整理

- 收件箱列表由“直接转文章/知识”改为“整理内容”。
- 整理时可以设置：
  - 目标类型
  - 标题与 URL 标识
  - 摘要
  - 可见性
  - 标签
  - 所属专栏与主专栏
  - 关联知识节点
  - 知识节点类型
- 专栏和节点支持搜索筛选。
- 整理完成后自动打开对应正式编辑器。

### 5. 标准化内容创建

- 整理为文章时创建正式 `Article`，同步文章专栏、标签、节点引用、版本和搜索影子。
- 整理为知识时创建正式 `KnowledgeNode`，同步专栏、标签、节点关系、版本和 RAG 索引。
- 不再把文章或知识内容仅写入旧的通用 `ContentEntry`。
- 项目和阅读仍保留通用内容模式，等待后续独立模型升级。

- 新增标准化文章整理与关系测试。
- 新增组织统计、孤立内容和反向链接测试。
- Python 编译检查通过。

- Git 差异格式检查通过。

## 当前边界

- 跨类型关系仍使用现有标准化关联表，不允许创建任意字符串关系。
- 孤立内容需要人工判断后关联，不执行自动修复。
- 项目与阅读尚未像文章和知识节点一样拥有独立标准化表。
