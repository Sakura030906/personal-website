# 第二大脑第八轮：AI 内容增强与字段级确认

## 本轮目标

让 AI 能够辅助完善已经进入正式知识模型的文章和知识节点，同时确保任何建议都经过人工逐字段确认，并继续进入现有版本历史与活动审计。

## 已完成

### 1. 文章内容增强

- 为正式 `Article` 模型生成摘要、标签、SEO 标题、SEO 描述和关联知识节点建议。
- 支持本地规则分析与真实模型增强两种模式。
- 本地模式会利用已有标签、技术关键词和内容相似度，不依赖外部模型。
- 模型不可用时不会阻塞编辑，仍可继续使用本地建议。

### 2. 知识节点增强

- 为正式 `KnowledgeNode` 生成摘要、标签、关联文章和关联节点建议。
- 关联文章写入标准化 `ArticleNode`。
- 关联节点写入标准化 `KnowledgeRelation`，并标记为“AI 辅助发现”。
- 新关系继续参与知识图谱、RAG 检索和反向链接。

### 3. 字段级差异确认

- CMS 并排展示当前值与建议值。
- 每个字段可单独勾选或取消。
- 未改变字段不可误选。
- 应用前必须至少确认一个字段。
- 标题和正文不在自动增强范围内。

### 4. 并发和版本安全

- 每份建议绑定生成时的 `revision`。
- 内容在建议生成后被修改时，应用请求返回 `409`，必须重新生成。
- 应用前保存 `before_ai_enhancement` 版本快照。
- 应用完成后 revision 自动递增。
- 可继续使用原有版本恢复功能撤销增强结果。

### 5. 审计与发布边界

- 每次应用写入 `ai_enhancement_applied` 活动记录。
- 审计内容包含采用的字段列表。
- AI 增强不会改变草稿、发布或归档状态。
- AI 增强不会自动公开私有内容。
- AI 增强不会自动发布文章。

## API

- `POST /admin/articles/{id}/enhancement/suggest`
- `POST /admin/articles/{id}/enhancement/apply`
- `POST /admin/knowledge-nodes/{id}/enhancement/suggest`
- `POST /admin/knowledge-nodes/{id}/enhancement/apply`

`suggest` 支持 `local` 和 `auto`；`apply` 必须提交 `expected_revision`、选中字段与建议内容。
